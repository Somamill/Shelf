Audiobooks · BookPlayer ↔ Hardcover

BookPlayer can send audiobook reading status to Hardcover. That link is configured on the iPhone in BookPlayer → Settings → Integrations → Hardcover. BookPlayer currently sends status only; it does not send its live audio position to Hardcover. Shelf reads the Hardcover shelf rather than BookPlayer’s private player database. The current BookPlayer integration sends reading status, not the live audio position. Audiobookshelf is not used.

Automatic reader matching

Shelf matches exact file fingerprints first, then unique embedded identifiers such as ISBN, followed by title and author. Readest can omit metadata in its KOReader Sync integration: in Readest, open a book → Book Menu → KOReader Sync, enable Send Document Metadata, choose File Content matching, and sync again. The bridge retries saved records automatically; ambiguous matches stay unlinked. Readest ↔ KOReader guide ↗

KOReader tools already included

KOReader Sync sends reading position; Calibre and OPDS browse your library; Statistics and Read Timer track reading. For annotations, use KOReader's built-in Export Highlights and choose Readwise. Highlights use their own export path and are not part of the progress sync.
